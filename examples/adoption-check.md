# jev-fingerprint — contrôle d’adoption · adoption check · comprobación de adopción

## Français

Point de départ local, après la préparation indiquée dans le README :

```sh
npm run demo:report
```

Des erreurs qui ne diffèrent que par un identifiant variable peuvent rejoindre un même groupe proposé. Vérifiez le motif normalisé avant toute fusion dans un outil externe.

## English

Local starting point, after the setup described in the README:

```sh
npm run demo:report
```

Errors differing only in a variable identifier may enter one proposed group. Inspect the normalized pattern before merging anything in an external tracker.
